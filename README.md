# Banking-System-Java 🏦

A complete Banking Management System built in Core Java using Object-Oriented Programming concepts.

## 🚀 Features
- Account Creation & Management
- Deposit & Withdraw Functionality
- Balance Inquiry
- Transaction History with Date & Time
- Loan Management (Home, Car, Personal, Education)
- Customer KYC Verification
- Interest Calculation & EMI Calculator
-  Customer management system
- Transaction history (Deposit/Withdraw/Transfer)
- Balance inquiry and mini statement

## 🛠️ Tech Stack
- Java (Core Java)
- OOP Concepts - Inheritance, Encapsulation, Polymorphism
- Collections Framework (ArrayList)
- LocalDateTime API
- **Fixed Deposit (FD)** - Interest calculation, Maturity, Premature withdrawal, Tax saving FD
- **Credit Card System** - Silver/Gold/Platinum cards, Limit management, Bill generation, EMI conversion, Reward points
- **Net Banking** - Secure login, IMPS/NEFT/RTGS fund transfer, Bill payment (BBPS), Beneficiary management, OTP security

## 📁 Project Structure
- `Main.java` - Entry point & Menu driven system
- `Account.java` - Account operations logic
- `Bank.java` - Bank management
- `Customer.java` - Customer details & KYC
- `Transaction.java` - Transaction history tracking
- `Loan.java` - Loan eligibility & EMI calculation
